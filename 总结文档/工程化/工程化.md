# 工程化

## 说说对SSG的理解

SSG（Static Site Generation，静态站点生成）是指在构建时将页面预先生成成静态 HTML 文件，而不是在每次请求时动态生成。这样可以提高页面加载速度和 SEO 性能，因为用户访问时直接获取静态文件，无需等待服务器渲染。常见的实现方式包括 Next.js 的 `getStaticProps` 和 `getStaticPaths`。

相比于 SSR（Server-Side Rendering，服务端渲染），SSG 的优势在于：

- 更快的页面加载速度，因为静态文件可以通过 CDN 分发。
- 更好的 SEO，因为搜索引擎可以直接抓取完整的 HTML。
- 减轻服务器压力，因为不需要每次请求都进行渲染。

但是 SSG 也有局限性：

- 构建时间较长，尤其是页面数量很多时。
- 对于频繁更新的数据，可能需要结合 ISR（Incremental Static Regeneration）来实现增量更新。
