# 技能：工业野性主义与战术遥测界面工程

## 1. 技能元信息

**名称：** 工业野性主义与战术遥测界面工程
**描述：** 对网页界面进行架构设计的高级能力，综合中世纪后期瑞士版式设计、工业制造手册以及复古未来主义航天/军事终端界面。该方向要求完全掌握刚性模块化网格、极端排版尺度对比、纯功利性色板，以及模拟模拟退化效果（半色调、CRT 扫描线、位图抖动）的编程实现。目标是构造数字环境，传达原始功能性、机械精度和高信息密度，故意摒弃传统消费型 UI 设计模式。

## 2. 视觉原型

该设计系统通过融合两种截然不同但高度兼容的视觉范式运作。**每个项目选择一个并坚持，不要在同一界面中切换或混合两种模式。**

### 2.1 瑞士工业印刷

源于 1960 年代的企业识别体系和重型机械蓝图。

- **特征：** 高对比度浅色模式（新闻纸/米白底板）。依赖巨大的、厚重的无衬线字体。用清晰分隔线勾勒严厉的结构网格。负空间使用极其不对称，穿插着超大、突破视口的数字或字母。大量使用主红色作为警报/强调色。

### 2.2 战术遥测与 CRT 终端

源自机密军事数据库、传统主机和航空航天头盔显示界面（HUD）。

- **特征：** 暗色模式专用。高密度表格数据显示。绝对以等宽字体为主。集成技术化边框装置（ASCII 方括号、十字准线）。应用模拟硬件限制（磷光发光、扫描线、低位深渲染）。

## 3. 字体排版架构

排版是主要结构与装饰基础，图像为次要。该系统要求极端的尺度、字重和间距变化。

### 3.1 宏观排版（结构标题）

- **分类：** Neo-Grotesque / Heavy Sans-Serif
- **优选 Web 字体：** Neue Haas Grotesk（Black）、Inter（Extra Bold/Black）、Archivo Black、Roboto Flex（Heavy）、Monument Extended
- **实现参数：**
**规模：** 使用流体字体在大尺度下部署，例如 `clamp(4rem, 10vw, 15rem)`。
**字距（Letter-spacing）：** 极度紧凑，常为负值（`-0.03em` 到 `-0.06em`），让字形形成坚实的建筑块体。
**行距（Line-height）：** 极度压缩（`0.85` 到 `0.95`）。
**大小写：** 仅使用大写，增强结构冲击力。

### 3.2 微观排版（数据与遥测）

- **分类：** 等宽 / 技术 Sans
- **优选 Web 字体：** JetBrains Mono、IBM Plex Mono、Space Mono、VT323、Courier Prime
- **实现参数：**
**规模：** 固定且小（`10px` 至 `14px` / `0.7rem` 至 `0.875rem`）。
**字距：** 适度松散（`0.05em` 到 `0.1em`），模拟机械打字机或终端矩阵间距。
**行距：** 标准到紧凑（`1.2` 到 `1.4`）。
**大小写：** 全部大写，应用于元数据、导航、单元 ID 和坐标。

### 3.3 纹理对比（艺术性打断）

- **分类：** 高对比衬线
- **优选 Web 字体：** Playfair Display、EB Garamond、Times New Roman
- **实现参数：** 仅极少量使用。必须经过大量后处理（半色调滤镜、1-bit 抖动），以弱化矢量的完美感，并与干净的无衬线形成纹理铺垫。

## 4. 色彩系统

色彩架构绝不妥协。渐变、柔和阴影和现代半透明效果被严格禁止。颜色模拟物理介质或原始发光显示器。

**关键：每个项目仅选一个底板调色板并保持一致。不要在同一界面中混合浅色和深色底板。**

### 如果是瑞士工业印刷（浅色）

- **背景：** `#F4F4F0` 或 `#EAE8E3`（哑光、未漂白的文档纸）
- **前景：** `#050505` 至 `#111111`（碳素墨）
- **强调：** `#E61919` 或 `#FF2A2A`（航空/危险红）。这是唯一的强调色。用于删除线、厚结构分隔线或重要数据高亮。

### 如果是战术遥测（深色）

- **背景：** `#0A0A0A` 或 `#121212`（停用的 CRT。避免纯 `#000000`）
- **前景：** `#EAEAEA`（白磷光）。这是主文本颜色。
- **强调：** `#E61919` 或 `#FF2A2A`（航空/危险红）。规则相同。
- **终端绿色（`#4AF626`）：** 可选。仅用于单一特定 UI 元素（例如一个状态指示器或一个数据读数）——绝不能作为常规文字颜色。如果没有明确目的，则完全省略。

## 5. 布局与空间工程

布局必须呈现出数学化工程感，拒绝传统网页 padding，而是使用明显区隔来表达结构。

- **蓝图网格：** 严格遵循 CSS Grid 架构。元素不漂浮，而是精确锚定到网格轨道与交集处。
- **明显分区：** 大量使用实心边框（`1px` 或 `2px solid`）来分隔不同信息区域。水平规则（`<hr>`）常跨整个容器宽度，隔离操作单元。
- **双模密度：** 布局在极端数据密度（紧密堆叠的等宽元数据）与大面积计算后的负空间之间摇摆，以框定宏观排版。
- **几何：** 绝对拒绝 `border-radius`。所有角必须为 90°，以维持机械刚性。

## 6. UI 组件与符号学

标准网页 UI 惯例被功能性、工业化图形元素取代。

- **语法装饰：** 使用 ASCII 字符来标记数据点。
_框架：_ `[ DELIVERY SYSTEMS ]`、`< RE-IND >`
_方向：_ `>>>`、`///`、`\\`
- **工业标记：** 大量使用注册符号（®）、版权符号（©）和商标符号（™），它们作为结构几何元素而不是法务文案。
- **技术资产：** 在网格交点处集成十字准线（`+`）、重复垂直线（条形码）、厚横向警示条纹，以及随机字符串数据（例如 `REV 2.6`、`UNIT / D-01`），模拟活跃的机械处理过程。

## 7. 纹理与后处理效果

为避免设计看起来过于数字化，模拟的模拟退化效果会通过 CSS 和 SVG 过滤器植入前端。

- **半色调与 1-bit 抖动：** 将连续色调图像或大型衬线排版转换为点阵图案。通过预处理或 CSS `mix-blend-mode: multiply` 覆盖层配合 SVG 径向点图案实现。
- **CRT 扫描线：** 对终端界面，应用 `repeating-linear-gradient` 作为背景，模拟水平电子束扫描（例如 `repeating-linear-gradient(0deg, transparent, transparent 2px, rgba(0,0,0,0.1) 2px, rgba(0,0,0,0.1) 4px)`）。
- **机械噪声：** 将低不透明度 SVG 静态/噪声过滤器应用到 DOM 根元素，给浅色和深色模式统一引入物理颗粒感。

## 8. Web 工程指令

1. **网格确定性：** 使用 `display: grid; gap: 1px;` 结合对比鲜明的父子背景色，生成数学上完美、极窄的分割线，而不需要复杂边框声明。
2. **语义刚性：** 使用精确的语义标签（`<data>`、`<samp>`、`<kbd>`、`<output>`、`<dl>`）构建 DOM，以准确反映遥测的技术性质。
3. **排版钳制：** 仅对宏观排版使用 CSS `clamp()` 函数，确保超大字号在不同视口下稳健扩展，同时保持结构完整性。

## 9. 结论

工业野性主义 UI 的关键，不在于“看起来很酷”，而在于“看起来像一台机器、一套蓝图、一份真正的工程文档”。它与消费者式 UI 相反：抛弃情绪和修饰，保留结构、强度和信任感。真正好的界面不需要说服用户“这很时尚”，而是让用户觉得“这东西确实被设计成了工作工具”。
